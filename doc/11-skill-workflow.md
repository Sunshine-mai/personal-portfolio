# Skill 与协作流程

## 设计阶段

1. 产品范围评审：确认目标、边界和非目标，防止作品集膨胀为实验平台。
2. 工程方案评审：确认数据流、状态机、权限、测试和回滚。
3. 设计咨询：确定视觉语言、页面结构、知识网络表现和响应式策略。
4. 设计审查：高保真原型完成后检查层级、交互状态、可访问性和移动端。

## 开发阶段

1. 先完成一个纵向切片。
2. 每个功能点先说明影响文件和技术理由。
3. 修改后执行单元测试、接口测试和浏览器验证。
4. 发现问题先定位根因，再修复并补回归测试。
5. 每个阶段独立记录决策和交付结果。

## 发布阶段

1. 代码与内容评审。
2. 安全、秘密、依赖和许可证扫描。
3. 候选环境部署。
4. 浏览器和 API 冒烟。
5. 版本、构建产物和数据库迁移核对。
6. 人工确认后发布。
7. 发布后健康验证和复盘。

## 与用户背景的结合

- 用 `ai-translator` 作为 Python/FastAPI 真实案例。
- 用 Java RAG 项目作为 Java→Python 映射案例。
- 用合作项目诚实展示团队协作和个人贡献边界。
- 将每个技术概念连接到项目、决策和验证证据。
- 详细学习记录写入 `ai-dev-lab`，作品集只保留经过整理的公开摘要。
