# 从 0 到 1 交付路线

## 阶段 0：设计与素材审计

产出项目章程、PRD、信息架构、三个旧项目素材清单、隐私边界和成功标准。未完成前不写业务代码。

## 阶段 1：工程方案

产出架构、数据模型、API 契约、状态机、权限矩阵、威胁模型、测试方案、部署和回滚方案。技术栈和端口在此阶段末确认。

## 阶段 2：高保真原型

完成首页、项目列表、完整项目详情、知识网络、学习摘要、后台审核页面、错误和空状态。原型必须是真实内容、完整交互、响应式，用户确认后才能开发。

## 阶段 3：基础纵向切片

使用 Java 17 + Spring Boot 3 建立配置、MySQL/Flyway 数据库迁移、管理员认证、项目修订、一个项目的编辑→审核→发布→公开展示链路，并完成单元、接口和浏览器测试。

## 阶段 4：完整内容

录入三个经过审查的项目、技术栈、架构、决策、证据、外链、学习摘要和知识网络。

## 阶段 5：质量与安全

运行完整测试、秘密扫描、依赖扫描、许可证扫描、构建验证、浏览器验证、备份恢复和回滚演练。

## 阶段 6：部署与交付

预发布验证、候选版本冻结、人工批准、生产部署、冒烟测试、观察窗口、发布归档和工程复盘。

## 质量门

```text
G0 范围确认
→ G1 设计确认
→ G2 实现完成
→ G3 集成测试
→ G4 旧项目准入
→ G5 候选版本
→ G6 人工发布批准
→ G7 发布后验证
```

任何阻断项失败都必须停止推进，不以“先上线再修”替代修复。
