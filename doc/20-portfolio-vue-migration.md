# V5 正式前端迁移记录

## 范围

将 `prototype/portfolio-v5.html` 的信息架构和视觉方向迁移到 `project/frontend/` 的 Vue 3 + Vite 应用。正式页面继续只读取 `/api/public/projects` 的已发布内容，后端不可用时使用安全静态回退数据。

## 已实现

- 深色作品集视觉、字体层级、项目列表和响应式布局。
- 代表项目筛选：全部、独立开发、原型方案、合作项目。
- 项目详情抽屉，支持读取 `/api/public/projects/{slug}`。
- 工程方法、视觉与剪辑待补状态、关于我和复制邮箱反馈。
- 保留 Vite 代理：前端 `1001`，后端 `2001`。

## 验收边界

- 当前项目图片沿用 V5 原型路径 `/prototype/assets/v5/`；正式部署前应将已授权截图迁移到前端 `public/assets/`，避免部署时依赖原型目录。
- 后端项目字段以现有 Java `Project` 实体为准；标签和图片属于前端展示增强字段，未写入后端数据库。
- 正式测试应覆盖 API 成功、API 失败回退、筛选、详情抽屉、Escape 关闭和移动端导航。

### LexiFlow 边界证据采集过程（2026-09-10）

LexiFlow 的后两张截图由浏览器脚本驱动本地实跑采集，不是设计稿：

1. 启动后端（venv 解释器，端口 8000）与前端（Vite，端口 5173）。
2. 无头 Chrome 打开 `/translate`，填入英文句子并点击「翻译」，等待模型返回。
3. 同一浏览器会话内连续翻译，观察游客配额递减直到被拦截。
4. 截图被拦截后的页面状态。

实测结果：

```text
第 1 次  每天一小步，胜过一大步。        页面提示：游客今日可免费翻译 2 次
第 2 次  好工具融入工作之中。            页面提示：游客今日可免费翻译 1 次
第 3 次  交付真实存在的最小事物。        页面提示：游客今日可免费翻译 0 次
第 4 次  被拦截，前端跳转到登录页
```

结论：游客配额按匿名标识独立计数，耗尽后引导登录而不是静默失败。同一句子在不同次请求下译文会略有差异（模型输出非确定性），因此案例描述不声称译文可复现。

补充说明：首次采集时曾错误地认为配额未生效，实际原因是采集脚本用于提取页面文案的正则未匹配到嵌套元素，属于脚本缺陷而非产品缺陷。
