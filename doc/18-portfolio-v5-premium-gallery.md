# 个人作品集 V5 深色画廊原型

## 目标

V5 在 V4 的作品优先信息架构上做视觉与动效升级：深色高级感主题、图片优先的作品封面（真实项目截图）、徽章化的状态展示、滚动触发的轮播式序列入场、骨架屏流式加载。作品主体、详情抽屉、筛选、收藏等已验收交互全部保留。

## 原型访问

在项目根目录执行 `python -m http.server 4173 --directory prototype` 后打开 `http://127.0.0.1:4173/portfolio-v5.html`。V5 通过相对路径加载 CSS、JS 与 `assets/v5/` 下的真实截图，不依赖后端或构建工具。

## 设计方向

- **深色画廊**：深色底（`#0e1418` 系）、亮色文字、单一强调色；卡片使用真实项目截图作为封面，状态与验证等级以徽章形式叠加在封面上。
- **轮播式入场**：作品卡片随滚动逐件滑入（`IntersectionObserver` 触发 + `transition-delay` 序列），首屏两件精选作品优先呈现；动画只做揭示，不接管滚轮。
- **骨架屏加载**：图片封面在加载完成前显示呼吸态骨架，`onload` 后淡入真实图片（blur-up 的轻量近似）。
- **阅读体验**：保留顶部导航、阅读进度线、章节脚注与滚动吸附（proximity），移动端关闭吸附。
