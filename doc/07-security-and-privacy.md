# 安全与隐私基线

## 1. 必须保护的内容

- 管理员会话。
- 草稿和未公开内容。
- 合作项目内部资料。
- API Key、密码、Token、私钥和数据库连接信息。
- 证据附件、日志和真实用户数据。

## 2. 管理端安全

- 公开浏览与管理写入分离。
- 管理操作必须由服务端会话授权。
- Cookie 会话使用 `HttpOnly`、`Secure` 和合理的 `SameSite`。
- 登录失败限流，敏感操作审计。
- 发布、下线、删除需要二次确认。
- 不信任前端传入的用户 ID、角色或状态。

## 3. 内容安全

- Markdown/富文本使用白名单清洗。
- 默认 HTML 转义，阻止脚本、事件属性和危险协议。
- URL 仅允许 HTTP/HTTPS。
- 外链核验防 SSRF：阻止 localhost、私网、链路本地和云元数据地址，并限制重定向、响应体和超时。
- 附件限制类型、大小和路径，禁止可执行文件。

## 4. 项目上传安全

扫描当前树、Git 历史、构建产物、镜像层、日志、截图和数据库导出。发现凭据时必须吊销并轮换，不能只删除文件。

## 5. 数据公开分级

- `public`：可公开展示。
- `redacted`：脱敏后可公开。
- `private`：仅后台可见。
- `restricted`：只保留存在和核验结果，不展示原文件。

## 6. 作品集的安全边界

本项目不提供任意代码执行、源码自动运行、容器启动、依赖安装或实验任务 API。未来实验平台必须是独立项目。
