How I work

我通常这样做项目。

先把问题说清楚，再动手实现。过程中会记录取舍，并用实际测试确认结果。

01 / PLAN

先把问题拆开

确认目标、范围、数据怎么流，以及这次不做什么。

02 / TEST

做完以后再验证

跑单元测试、接口测试和浏览器操作，不只看页面能不能打开。

03 / REVIEW

把经验留下来

遇到的问题、做过的取舍和下一步计划，都会写进记录。

Project workflow

从想法到可以交付。

我会把工作拆成几步，每一步都有结果，不把问题留到最后一起处理。

01定义问题

目标、用户、边界和不做什么。

02记录决策

比较方案，解释选择与代价。

03小步实现

每个功能独立可运行和可验证。

04多层验证

单元、接口、浏览器和部署检查。

05交付复盘

版本、隐私、证据、回滚和经验沉淀。
